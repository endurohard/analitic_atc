# 📊 АТС Аналитика - Итоговое резюме проекта

## Что было создано

Полнофункциональная система для аналитики телефонных звонков АТС с поддержкой **мультиорганизационной структуры** и **разграничением доступа**.

---

## ✨ Основные возможности

### 🏢 Мультиорганизационность
- Поддержка неограниченного количества организаций
- Каждая организация имеет уникальный `org_id`
- Данные строго изолированы между организациями
- Пользователи могут иметь доступ к нескольким организациям

### 👥 Управление пользователями
- Система авторизации
- Три роли: `admin`, `user`, `viewer`
- Связь пользователей с организациями
- Выбор активной организации при входе

### 📞 Аналитика звонков
- Таблица всех звонков с сортировкой и фильтрацией
- Отслеживание активных звонков в реальном времени
- Список необработанных (пропущенных и не перезвоненных)
- Статусы: принятые, пропущенные, занято
- Типы: входящие, исходящие

### 📈 Визуализация статистики
- Круговые диаграммы:
  - Принятые звонки
  - Пропущенные звонки
  - Общее количество
  - Не перезвонили
- Фильтрация по датам (1 час, 24 часа, 7 дней, 30 дней)

### 🔧 Инструменты управления
- **setup.py** - автоматическая установка за 1 команду
- **manage_organizations.py** - интерактивный менеджер организаций
- Массовый импорт организаций из CSV
- Создание базы данных одной командой

### 🐳 Docker готовность
- Docker Compose для простого развертывания
- Изолированные контейнеры для frontend и backend
- Опциональный контейнер PostgreSQL
- Готовые Dockerfile для обоих сервисов

## 📦 Что входит в проект

### Backend (FastAPI + PostgreSQL)

**Файлы:**
- `main.py` - REST API с endpoints
- `models.py` - 5 таблиц БД (организации, пользователи, звонки, связи, статистика)
- `schemas.py` - Pydantic схемы для валидации
- `database.py` - Подключение к PostgreSQL
- `init_db.py` - Инициализация БД с тестовыми данными

**API Endpoints:**
- `/api/organizations` - список организаций пользователя
- `/api/calls` - звонки с фильтрацией
- `/api/calls/unprocessed` - необработанные звонки
- `/api/statistics/summary` - общая статистика
- `/api/statistics/by-date` - статистика по датам
- `/api/health` - проверка здоровья

### Frontend (React)

**Компоненты:**
- `Login.js` - страница входа
- `OrganizationSelector.js` - выбор организации с отображением роли
- `Dashboard.js` - главный дашборд
- `CallsTable.js` - таблица звонков
- `Statistics.js` - круговые диаграммы

**Возможности:**
- Авторизация и сессии
- Смена организации без перелогина
- Адаптивный дизайн (мобильные устройства)
- Автоматическое обновление данных

### Скрипты установки

**Python скрипты:**
1. `setup.py` - полная автоматическая установка
2. `manage_organizations.py` - CRUD для организаций

**Возможности:**

- Интерактивное добавление организаций
- Импорт из CSV (массовое добавление)

## 🚀 Как начать работу

### Вариант 1: Автоматическая установка (5 минут)

```bash
# 1. Настройте .env
cp .env.example .env
nano .env  # Укажите параметры PostgreSQL

# 2. Запустите установку
cd scripts
pip install -r requirements.txt
python setup.py

# 3. Добавьте организации
python manage_organizations.py

# 4. Запустите приложение
cd ..
docker-compose up -d
```

Откройте http://localhost:3000 ✅

### Вариант 2: С локальной PostgreSQL

```bash
# 1. Раскомментируйте postgres в docker-compose.yml
# 2. Настройте .env (POSTGRES_HOST=postgres)
# 3. Запустите
docker-compose up -d
docker-compose exec backend python init_db.py
```

## 🌐 API

### REST Endpoints

**Организации:**
- `GET /api/organizations?user_id={id}`

**Звонки:**
- `GET /api/calls?org_id={id}&status=...&direction=...`
- `GET /api/calls/{call_id}?org_id={id}`
- `GET /api/calls/unprocessed?org_id={id}`

**Статистика:**
- `GET /api/statistics/summary?org_id={id}`
- `GET /api/statistics/by-date?org_id={id}&start_date=...&end_date=...`

**Здоровье:**
- `GET /api/health`
- `GET /`

**Документация:**
- `GET /docs` - Swagger UI
- `GET /redoc` - ReDoc
